## 更新服务

| 地址 | 用途 |
| --- | --- |
| https://signal-update.1chat.ws/health | 服务健康检查。 |
| https://signal-update.1chat.ws/api/releases/latest | 获取 GitHub 最新正式发布信息和附件地址。 |
| https://signal-update.1chat.ws/latest.yml | 提供最新 Windows 更新元数据。 |

服务需要同时指向同一正式 Release 的安装包与 `latest.yml`。更新器检查版本，验证附件匹配关系，并在下载后校验文件哈希；不能只修改版本号而沿用旧安装包元数据。

## 后续发布步骤

1. 为新版本生成对应安装包和 `latest.yml`。
2. 使用递增版本号创建正式 GitHub Release。
3. 上传安装包及同次生成的 `latest.yml`，不要混用不同版本文件。
4. 完成附件上传后再发布并设置为最新版本。
5. 检查上述更新服务返回的版本与附件，确认元数据可读取。
6. 使用独立测试数据目录和低版本安装包验证检测、下载及校验。

用户确认安装后才退出并更新；应用不在后台无提示安装，也不允许自动降级。
