# 使用指南

## 1. 登录与关联 Signal

1. 安装并打开“Signal-AI翻译专版”。
2. 在登录页面输入 OneChat 激活码，登录翻译服务。
3. 若当前账号未关联 Signal，在手机 Signal 中进入关联设备页面，扫描桌面端二维码并完成关联。
4. 等待同步完成后开始使用。

激活码和 Signal 设备关联是两个步骤：前者用于本专版的服务授权，后者用于访问对应 Signal 账号。翻译服务需要可用网络和有效授权。

## 2. 接收消息翻译

打开右侧“翻译设置”，启用“自动翻译收到的文字消息”，选择接收译文语言，并保存当前账号设置。

收到文字消息后，译文显示在原始消息下方。原始正文保留，便于对照。翻译不修改对方发送的消息；已有有效译文会保存到该账号的本地消息数据库，重新打开会话时复用。

译文缓存与具体消息和翻译配置关联。原文被编辑、目标语言或通道改变等使缓存失效的情形，可能重新翻译；网络或服务不可用时，也可能在后续重新尝试。缓存不意味着所有设置变更后都永不再请求。

本版本针对文字消息正文提供翻译，不提供图片 OCR、语音转写或附件全文翻译。

## 3. 翻译后发送

在翻译设置中启用“显示发送翻译栏”，选择发送目标语言。翻译框顶部可快速切换通道和语言。

1. 在新增的下方翻译框输入原文。
2. 按 `Enter` 发起翻译，结果填入 Signal 自己的原生输入框，焦点移入原生框。
3. 检查译文；需要时可直接修改。
4. 再次按 `Enter`，通过 Signal 原生发送流程发送正文。
5. 发送结束后，焦点回到下方翻译框，方便继续输入下一条。

第一次回车只翻译并填入，不直接发送。下方翻译框使用 `Shift + Enter` 换行。中文输入法选词不触发翻译。翻译失败时会提示错误并保留原文。

也可直接在原生 Signal 输入框打字发送，发送后焦点留在原生框。通过翻译框发送的消息在本机显示对应输入原文，不将原文附加给对方；若实际发送正文与翻译草稿不匹配，不会把旧原文强行关联到新消息。

翻译设置可选“译文校验”，启用后会增加一次翻译请求。通道可用性、支持语言及服务额度以当前 OneChat 服务为准。

## 4. 多账户

点击顶部账号列表后面的 `+` 添加账号，并独立完成 Signal 设备关联。点击账号标签切换；标签显示账号头像、昵称和未读角标。

每个账号的持久化 Session、数据库密钥、消息数据库、配置和附件目录独立。当前账号的翻译开关、接收语言、发送语言、通道、指纹和代理配置分别保存，不会因切换账号而直接套用另一账号的设置。

OneChat 激活状态及翻译服务连接由同一个应用共享，不是为每个 Signal 账号重复建立授权连接。新增账号默认折叠左侧导航选项卡，可根据需要展开。

## 5. 浏览器指纹

切换到目标账号，打开右侧“环境配置”，启用指纹配置后可设置：

| 配置 | 说明 |
| --- | --- |
| 地区 | 跟随系统，或选择内置地区档案，使语言、时区和定位参数按档案匹配。 |
| 操作系统 | 选择 Windows、macOS、Linux、Android 或 iOS 的浏览器属性表现。 |
| 浏览器版本 | 设置用于生成浏览器属性的版本。 |
| User-Agent | 自定义；留空时按所选系统和版本生成。 |
| WebRTC | 允许、隐藏内网地址，或禁止非代理 UDP。 |
| 地理位置 | 禁止，或按所选地区匹配。 |
| 分辨率 | 跟随电脑，或自定义宽度、高度。 |
| 字体 | 使用系统默认策略，或随机匹配策略。 |
| 生成随机指纹 | 生成一组可再编辑的浏览器环境参数。 |

点击“保存并应用当前账号”后重新加载该账号，使配置生效。保存前请完成或保存正在编辑的内容。

这些参数作用于桌面页面的浏览器属性，不修改手机号、Signal 账号、设备密钥或服务端设备身份；不要把它理解为改变 Signal 设备身份的功能。Signal 原生音视频连接不由浏览器 WebRTC 设置控制。

## 6. 代理 IP

在目标账号的“环境配置”中启用代理，填写协议、代理 IP 或主机名、端口及可选用户名、密码。

- 支持 SOCKS5、HTTP、HTTPS（HTTP CONNECT）选项。
- SOCKS5 支持用户名和密码认证。
- “检测代理 / 出口 IP”用于验证连通性，显示检测到的出口 IP 和延迟。
- “保存并应用当前账号”保存配置并重载该账号。

代理用于当前账号的 Signal 消息、附件及页面网络。各账号可以设置不同代理；共享 OneChat 翻译连接、应用更新以及 Signal 原生音视频不保证经过该账号代理。代理配置不会替你购买或提供代理服务。

代理认证信息在本机加密保存。迁移、删除数据目录或更换电脑前，应备份必要配置和聊天数据。

## 7. 软件更新

安装 8.29.1 后，应用启动会自动检查，运行中也会定期检查。侧边栏“软件更新”可手动检测。

发现更高版本后后台下载并校验；下载完成出现更新提示。可选择稍后，或点击“立即安装”退出并重启安装。更新不会自动降级，也不会在你尚未确认时直接安装。

旧版 8.29.0 不含本项目自动更新器，先从 Release 手动安装 8.29.1。开发模式不会下载或安装更新，更新流程在 Windows 安装版中生效。

右侧栏顶部为“翻译设置、环境配置”，底部为“软件更新、联系客服、退出登录”。联系客服直接打开 https://t.me/onechat_help 。退出登录返回激活码页面，关闭自动登录、清除保存的激活码并取消待处理翻译，保留 Signal 关联、聊天记录及各账号配置。再次登录时输入激活码；如需自动登录，可重新勾选。

8.29.2 默认窗口为 1280×860，并限制在屏幕工作区内。其他保存过的自定义尺寸继续沿用。登录页版本号跟随实际应用版本。

## 8. 本地保存与服务处理

聊天记录使用 Signal 本地数据库，增加译文和发送原文元数据。重复打开有有效缓存的消息时使用本地译文。消息编辑、撤回、擦除等状态变化会更新或使相关缓存失效。

开启翻译时，需翻译的正文会提交到 OneChat 服务处理。关闭当前账号的接收自动翻译可停止新增接收正文的自动翻译请求。关闭发送翻译栏后仍可通过 Signal 原生输入框发送。

当前版本不包含统计和 AI 助手；账号栏、翻译、环境配置和更新为本专版的主要扩展功能。
